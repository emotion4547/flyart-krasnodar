

# Анализ сайта FlyArt: исправление нерабочих элементов

## Обнаруженные проблемы

### 1. Страница 404

| Страница | Где используется | Проблема |
|----------|------------------|----------|
| `/sitemap` | Footer → "Карта сайта" | Страница не существует, роут не определён |

### 2. Кнопки без действия

| Кнопка | Расположение | Проблема |
|--------|--------------|----------|
| "Заказать" | Header (десктоп) | Нет onClick или ссылки |
| "Заказать шары" | Мобильное меню | Нет onClick или ссылки |

### 3. Нерабочие ссылки на категории в Footer

Ссылки в футере используют неправильные slug:

| Ссылка | URL | Реальный slug в БД |
|--------|-----|-------------------|
| "Для девочки" | `/catalog/girl` | `dlya-devochki` |
| "Для мальчика" | `/catalog/boy` | `dlya-malchika` |
| "Для девушки" | `/catalog/woman` | `dlya-devushki` |
| "Для мужчины" | `/catalog/man` | `dlya-muzhchiny` |
| "Выписка" | `/catalog/discharge` | Не найден |
| "Гендер пати" | `/catalog/gender-party` | Не найден |

### 4. Неактуальные контакты

| Где | Проблема |
|-----|----------|
| Header (моб. меню) | Тестовый номер `+7 (900) 123-45-67` |
| Footer | Тестовый номер `+7 (900) 123-45-67` |
| Страница Contacts | Неправильная ссылка Telegram |

## План исправлений

### Шаг 1: Исправить кнопки "Заказать"

**Файл:** `src/components/layout/Header.tsx`

- Кнопка "Заказать" в десктопе → открывает диалог обратного звонка (CallbackDialog)
- Кнопка "Заказать шары" в мобильном меню → то же самое

### Шаг 2: Создать страницу Sitemap

**Новый файл:** `src/pages/Sitemap.tsx`

Страница со списком всех разделов сайта:
- Главная
- Каталог (с подкатегориями)
- Доставка и оплата
- Гарантия
- Отзывы
- Контакты
- Политика конфиденциальности
- Публичная оферта

**Файл:** `src/App.tsx` — добавить роут `/sitemap`

### Шаг 3: Исправить ссылки категорий в Footer

**Файл:** `src/components/layout/Footer.tsx`

Два варианта:
1. Использовать правильные slug из БД
2. Загружать категории динамически

Рекомендую вариант 1 — заменить на реальные slug:
- `/catalog/girl` → `/catalog/dlya-devochki`
- `/catalog/boy` → `/catalog/dlya-malchika`
- и т.д.

### Шаг 4: Обновить контактные данные

**Файлы:**
- `src/components/layout/Header.tsx` — заменить телефон на `+7 (923) 771-40-04`
- `src/components/layout/Footer.tsx` — заменить телефон на `+7 (923) 771-40-04`
- `src/pages/Contacts.tsx` — исправить Telegram на `https://t.me/FlyArtKRSK`
