# Обновления 27.01.2026

## Интеграция YooKassa

### Настройка платёжной системы
- Подключена YooKassa с боевыми ключами (Shop ID: 1251407)
- Сохранены credentials в таблице `settings` (key: `payment`)
- Включена онлайн-оплата (`onlinePayment: true`)

### Edge Functions
- `yookassa-init` — инициализация платежа, создание ссылки на оплату
- `yookassa-callback` — обработка уведомлений от YooKassa (webhook)

### Обновления базы данных

#### RLS-политики
- Добавлены INSERT политики для `anon` на таблицы `orders` и `order_items`
- Добавлены SELECT политики для `anon` и `authenticated` на таблицы `orders` и `order_items`

#### Constraint `orders_status_check`
Обновлён список допустимых статусов заказа:
- `new` — новый заказ
- `pending_payment` — ожидает оплаты
- `paid` — оплачен
- `processing` — в обработке
- `delivering` — доставляется
- `delivered` — доставлен
- `cancelled` — отменён
- `payment_failed` — ошибка оплаты

### Изменения в Checkout

#### Валидация email для онлайн-оплаты
- Email стал обязательным при выборе "Оплатить онлайн" (требование 54-ФЗ для фискализации)
- Добавлены две схемы валидации:
  - `baseCheckoutSchema` — email необязателен (для оплаты при получении)
  - `onlinePaymentCheckoutSchema` — email обязателен (для онлайн-оплаты)

#### UI изменения
- Лейбл email динамически меняется: `Email *` для онлайн-оплаты, `Email (необязательно)` для других способов
- Добавлена подсказка "Для отправки электронного чека" при онлайн-оплате

### Настройки способов оплаты
В таблице `settings` (key: `payment`) добавлены:
- `cardPayment: true` — оплата картой при получении
- `cashPayment: true` — оплата наличными
