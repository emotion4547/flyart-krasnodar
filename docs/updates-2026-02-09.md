### 2. Утилиты оптимизации изображений

Создан модуль `src/lib/imageOptimization.ts` с функциями-обёртками для изображений:
- `getProductCardImage()` — карточки товаров
- `getProductDetailImage()` — детальные страницы
- `getProductThumbnail()` — миниатюры
- `getCategoryImage()` — категории
- `getCartItemImage()` — корзина

> **Примечание:** Supabase Image Transformations (`/render/image/`) недоступны на текущем плане. Функции работают как passthrough (возвращают оригинальный URL) и готовы к активации при переходе на Pro-план.

### 3. Исправление ошибки загрузки фото товаров

**Проблема:** При добавлении фото товара в админке появлялась ошибка:
```
Unexpected token '<', "<html> <h"... is not valid JSON
```

**Причина:** Функции оптимизации использовали endpoint `/storage/v1/render/image/public/`, который требует Pro-план Supabase и возвращал HTML-страницу ошибки вместо изображения.

**Решение:** Функции оптимизации переведены в режим passthrough — возвращают оригинальные URL без трансформации.

#### Изменённые файлы
- `src/lib/imageOptimization.ts`
