# Обновления 05.03.2026

## Оптимизация производительности (11 пунктов)

### 1. Локальные шрифты вместо Google Fonts
- Удалён блокирующий `@import url('fonts.googleapis.com/...')` из `index.css`
- Добавлены `@font-face` с `font-display: swap` для Montserrat (300-700) и Playfair Display (400-600)
- Шрифты загружаются асинхронно, не блокируя рендеринг (~300-800мс экономии FCP)

### 2. Убран preload видео из index.html
- Удалена строка `<link rel="preload" href="/videos/hero-balloons.mp4" as="video">`
- Видео больше не конкурирует с критическими ресурсами за пропускную способность

### 3. Сжатие изображений при загрузке (Canvas API)
- Создана утилита `src/lib/imageCompression.ts`
- Автоматическое сжатие перед upload: ресайз до 1200px, WebP, quality 80%
- Интегрировано в `ImageUploader.tsx` и `MultiImageUploader.tsx`
- Пропускает файлы < 100KB и SVG

### 4. Lazy loading для изображений
- `decoding="async"` добавлен в `CollectionsSection.tsx`
- Все карточки товаров и категорий уже имели `loading="lazy"` и `decoding="async"`

### 5. Отложенная загрузка виджетов
- `FloatingContactButton`, `PWAInstallBanner`, `FortuneWheelTrigger`, `PendingSpinHandler` — загружаются через 3 секунды после монтирования через `React.lazy` + `setTimeout`
- Уменьшен начальный JS bundle и TBT

### 6. fetchpriority="high" для LCP
- Добавлен `fetchpriority="high"` на `<video>` в `HeroSection.tsx`

### 7. content-visibility: auto
- Добавлены CSS-свойства `content-visibility: auto` и `contain-intrinsic-size` в `LazySection.tsx`
- Браузер пропускает рендеринг невидимых секций

### 8. DNS prefetch для внешних доменов
- Добавлены `<link rel="dns-prefetch">` для `vk.com`, `t.me`, `api.telegram.org`
- Удалён лишний `preconnect` к `fonts.googleapis.com`

### 9. Удалена неиспользуемая анимация balloonFloat
- Удалены `.animate-balloon-float` и `@keyframes balloonFloat` из `index.css` (не использовались ни в одном компоненте)

### 10. Оптимизация логотипа
- Добавлены атрибуты `width={48} height={48}` к логотипу в `Header.tsx` для предотвращения CLS

### 11. Документация
- Создан данный файл `docs/updates-2026-03-05.md`

---

### Ожидаемый результат
- **FCP**: -300-800мс (неблокирующие шрифты)
- **LCP**: улучшение за счёт fetchpriority и убранного preload видео
- **TBT**: снижение за счёт отложенных виджетов
- **CLS**: 0 за счёт фиксированных размеров логотипа
- **Размер загружаемых изображений**: -40-60% благодаря сжатию при upload
