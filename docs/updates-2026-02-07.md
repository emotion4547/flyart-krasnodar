### 2. PWA — Динамическое обновление

#### Новая конфигурация
- `skipWaiting: true` — мгновенное обновление Service Worker
- `clientsClaim: true` — немедленный контроль над страницами
- `cleanupOutdatedCaches: true` — очистка старых кэшей

#### Стратегии кэширования
| Ресурс | Стратегия | TTL |
|--------|-----------|-----|
| Supabase API | NetworkFirst | 5 мин |
| Supabase Storage | CacheFirst | 7 дней |
| Google Fonts | CacheFirst | 1 год |
| Изображения | CacheFirst | 30 дней |

#### Новый логотип PWA
- Загружен `/public/pwa-icon.png` (муха с шариком)
- Обновлены все ссылки в манифесте и HTML
- Обновлён `PWAInstallBanner` компонент

#### Vendor Chunks
Разделение зависимостей для лучшего кэширования:
- `vendor-react` — react, react-dom, react-router-dom
- `vendor-ui` — radix-ui компоненты
- `vendor-query` — @tanstack/react-query
- `vendor-motion` — framer-motion

#### Изменённые файлы

### 5. Core Web Vitals оптимизация

#### LCP (Largest Contentful Paint)
- `preload` hero-видео в `index.html`
- `preconnect` к Supabase
- `preload="auto"` на video элементе

- Фиксированные `width` и `height` на изображениях
- `aspect-ratio` для видео
- `minHeight` на LazySection
