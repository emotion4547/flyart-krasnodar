# Обновления 10.03.2026

## Комплексный аудит и исправления

### 1. Исправлена регистрация — сохранение имени и телефона
- В `useAuth.tsx` метод `signUp` теперь передаёт `full_name` и `phone` через `options.data`
- Обновлён триггер `handle_new_user` в базе: записывает `phone` и `full_name` из metadata в таблицу `profiles`
- Ранее имя и телефон, введённые при регистрации, терялись

### 2. Серверная фильтрация каталога по категориям
- В `Catalog.tsx` фильтрация по категории перенесена с клиента на сторону базы данных
- Используется подзапрос через `product_categories` для получения только нужных товаров
- Решает проблему масштабирования при росте каталога (лимит 1000 строк)

### 3. Исправлен hardcoded телефон на странице благодарности
- В `OrderSuccess.tsx` заменён захардкоженный номер `+79001234567` на динамический из `useContactInfo`
- Телефон теперь подтягивается из настроек сайта

### 4. Копирование промокодов партнёров по клику
- На страницах `OrderSuccess.tsx` и `Partners.tsx` добавлена функция копирования промокода в буфер обмена
- При клике на промокод показывается toast-уведомление «Промокод скопирован»

### 5. Ограничение тоста купонов в корзине
- В `Cart.tsx` toast с активными купонами теперь показывается один раз за сессию
- Используется `sessionStorage` флаг `coupon-toast-shown` для предотвращения повторного показа

### 6. Рефакторинг useFavorites на React Query
- Хук `useFavorites.ts` переписан с `useState/useEffect` на `useQuery` и `useMutation`
- Добавлено кэширование, автоматический refetch, оптимистичные обновления
- Единообразие с остальными хуками проекта

### 7. PWA — защита OAuth от кэширования
- Добавлен `navigateFallbackDenylist: [/^\/~oauth/]` в конфигурацию workbox
- OAuth-редиректы теперь всегда идут через сеть, не кэшируются сервис-воркером
